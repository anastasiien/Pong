# Pong для iOS

Аркадная игра в стиле классического пинг-понга на Swift и UIKit. Игрок управляет ракеткой свайпами и играет против компьютера. Физика мяча построена на UIKit Dynamics, есть звуки ударов и тактильная отдача.

## Игра

- игрок двигает нижнюю ракетку свайпом, противник управляется компьютером;
- мяч запускается под случайным углом от 30° до 60° и после каждого удара о ракетку ускоряется на 4%;
- очко начисляется, когда мяч пролетает мимо ракетки противника;
- удары сопровождаются анимацией, звуком (разным для ракетки, стены и гола) и вибрацией;
- в фоне играет музыка.

## Как устроено

**Физика - UIKit Dynamics.** Мяч и ракетки - динамические объекты в `UIDynamicAnimator`:
- `UICollisionBehavior` отвечает за столкновения с ракетками и границами экрана, а делегат определяет, о какую границу ударился мяч, и начисляет очки;
- `UIDynamicItemBehavior` с упругостью 1.0 и нулевым сопротивлением делает отскоки без потери скорости;
- `UIPushBehavior` задает мячу стартовый импульс.

**Противник.** Таймер 24 раза в секунду сдвигает ракетку противника к мячу, но не быстрее заданной максимальной скорости, а каждый восьмой тик замедляет ее. Поэтому компьютер играет не идеально, и его можно обыграть.

**Структура кода.** Логика `PongViewController` разнесена по расширениям, каждое отвечает за свое:

| Файл | Что делает |
|---|---|
| `PongViewController.swift` | экран игры, счет, звуки, жизненный цикл |
| `+UIKitDynamics.swift` | физика и обработка столкновений |
| `+EnemyPaddleBehavior.swift` | поведение ракетки противника |
| `+GestureHandling.swift` | управление свайпами |
| `+LaunchBall.swift` | запуск мяча со случайным вектором скорости |
| `+BallHit.swift` | анимация и звук удара |
| `Utils/` | константы, звуки, вспомогательные функции |

## Запуск

Нужен Xcode 15+. Откройте проект в Xcode и запустите на симуляторе или iPhone.
